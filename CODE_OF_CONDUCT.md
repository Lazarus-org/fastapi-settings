# Code of Conduct

Everyone participating in `fastapi-settings` is expected to help maintain a respectful and welcoming environment.

- Discuss ideas and code constructively; avoid personal attacks, harassment, and discrimination.
- Respect different experience levels and provide actionable, considerate feedback.
- Keep discussions relevant to the project and respect maintainers' scope decisions.
- Do not disclose another person's private information or credentials.
- Follow the contribution and review workflow in [CONTRIBUTING.md](CONTRIBUTING.md).

Report conduct concerns privately to a maintainer listed in [AUTHORS.md](AUTHORS.md). Include the relevant context and avoid sharing sensitive details publicly. Report software vulnerabilities through [SECURITY.md](SECURITY.md).

Thank you for helping make the project useful and approachable.
